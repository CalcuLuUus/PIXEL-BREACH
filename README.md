# PIXEL//BREACH — 断层突围

一个运行在桌面浏览器中的像素风 3D 第一人称射击 Demo。

玩家需要进入失控的断层设施，穿过两波封锁，击败三阶段 Boss「零号守门者」，最后从解锁的出口撤离。

项目采用原生 HTML、CSS 和 JavaScript 实现，不需要构建工具、包管理器、外部模型或联网服务。场景、武器和工业设施均由程序化几何与材质生成。

## 游戏简介

**PIXEL//BREACH** 将低分辨率像素画面和工业科幻设施结合起来：

- 内部渲染分辨率为 `640×360`，再通过 CSS 像素化放大；
- 场景包含锈蚀钢板、混凝土墙面、管道、法兰、螺栓、电缆、警示条纹、维修设备和发光组件；
- 采用第一人称视角、鼠标转向和 Pointer Lock；
- 关卡流程为线性突入：入口维护区 → 管线走廊 → 中央能源大厅 → Boss 核心区 → 撤离出口。

## 当前实现的功能

### 核心玩法

- 3D 第一人称移动和鼠标视角控制；
- WASD 移动、冲刺和碰撞限制；
- Pointer Lock 鼠标锁定；
- 左键攻击和准星反馈；
- 敌人波次推进；
- 受伤、死亡、重试和暂停；
- Boss 击败后解锁出口；
- 靠近出口并按 `E` 完成撤离。

### 三种武器

1. **脉冲步枪**
   - 自动连射；
   - 30 发弹匣、120 发备用弹药；
   - Hitscan 远程攻击。
2. **裂能散射器**
   - 单次发射五发散射弹；
   - 8 发弹匣、48 发备用弹药；
   - 近距离爆发伤害。
3. **相位刃**
   - 无弹药限制；
   - 前方扇形近战攻击；
   - 可击退敌人并处理附近的敌方子弹。

三把武器都有独立的第一人称 ViewModel，包括枪身分层、导轨、螺栓、能源部件、枪管、握把、护手、能量核心和轻量动画。

### 角色技能

- `Shift`：普通冲刺；
- `Q`：相位突进，短时间快速移动并获得无敌效果，不能穿墙；
- `F`：过载脉冲，清除附近普通敌方子弹，对普通敌人造成伤害并减速，对 Boss 造成受限伤害；
- 技能具有冷却时间和 HUD 状态显示。

### 敌人与 Boss

- 第一波：4 个漂移哨兵；
- 第二波：4 个漂移哨兵与 2 个墙面炮台；
- Boss：零号守门者，160 HP；
- Boss 拥有三个阶段：
  - 第一阶段：横向移动、直线能量弹和攻击预警；
  - 第二阶段：环形护盾、激光/屏障、核心暴露和召唤；
  - 第三阶段：追踪弹、圆形冲击波、更快的攻击节奏和更小的安全区域。

### 视觉与技术

- 本地离线资源，不使用 CDN；
- `vendor/three.min.js` 是项目内置的本地 Three.js-compatible WebGL 子集，不是运行时下载的官方 CDN 文件；
- WebGL 低分辨率渲染；
- 环境光、方向光、Lambert 漫反射、边缘光、雾效、发光材质和加法混合；
- `MAX_LOCAL_LIGHTS=5` 的固定本地点光源阵列：入口冷青、维护灯暖色、管线锈色、能源核心、Boss 核心和出口共 6 个候选光源，每帧只启用距离/优先级最高的 5 个；
- 本地点光源具备距离衰减（8 级像素化阶梯）、法线漫反射和局部高光，会实际改变附近地面、墙面、管道和 Boss 装甲的颜色；
- 钢、锈蚀钢、铜、黄铜、混凝土、油污和 Boss 表面使用有限的 `specular` / `roughness` 参数生成像素化高光，不实现完整 PBR；
- `640×360` 内部渲染与像素化放大；
- 程序化静态 AO / 接触阴影：设备、箱体、立柱、管道法兰和墙脚；
- 入口维护区冷青主光配暖色灯具、锈蚀管线走廊橙锈色污染、Boss 核心区阶段色和出口解锁色的区域光近似，环境光色调随区域平滑过渡；
- 敌人与 Boss 使用固定 12 槽、复用几何/材质的双层动态接触阴影：柔和落点加沿方向光反方向偏移的深色核心；
- Boss 核心、出口、灯具、能源组件和敌人核心的分层像素辉光；
- **V3 电影化光效层（CINEMATIC FX）**：
  - 子弹使用“白热内核 + 颜色光晕 + 短暂拖尾”的三层像素表现，拖尾从固定 32 槽池中复用；
  - 玩家 Hitscan 曳光弹为白热芯、彩色中层、宽光晕和命中端闪点，固定 28 槽复用；
  - Boss 激光完整表现“预警线 → 充能收束 → 白热芯束 + 彩色中层 + 外层光晕 + 端点冲击”，颜色随 Phase 2 品红/紫、Phase 3 红/白变化，攻击时序与伤害逻辑不变；
  - 灯具、能源核心、Boss 核心/能量塔和出口使用低多边形加法锥体/柱体/体积片模拟体积光，固定上限 20 组，每组双层；
  - 命中火花、冲击环、枪口多层闪光、Boss 冲击波和屏幕闪光增强；火花固定 48 槽；
  - 地面/墙面加入方向性彩色反射条与“湿金属”高光响应，并让 Boss、激光和出口在地面产生动态色污染；这是程序化假反射，不是 SSR/光线追踪；
  - 所有瞬时 Mesh/Material 在启动时预建并复用，不在战斗循环中创建；
  - V3 运行时只读检查接口：`window.__PB_CINEMATIC_FX__.snapshot()` 和 `window.__PB_LIGHTING__.snapshot()`；
- 程序化生成工业像素场景与材质细节；
- CSS 扫描线、暗角、HUD 和像素化界面；
- 游戏运行时不请求网络资源。

> 当前版本使用有界的局部光照与像素化高光方案（最多 5 个同时生效的本地点光源、材质高光、合并 AO/双层接触阴影、多层加法光束/拖尾和假反射条），不包含 Shadow Map、全屏 Bloom、PBR、SSAO、SSR、全局光照或光追。

## 安装与运行

### 环境要求

- 支持 WebGL 的现代桌面浏览器；
- Python 3，或者任意静态 HTTP 文件服务器；
- 不需要 `npm install`，也不需要下载额外依赖。

### 使用 Python 启动

克隆仓库：

```bash
git clone git@github.com:CalcuLuUus/PIXEL-BREACH.git
cd PIXEL-BREACH
```

启动本地 HTTP 服务：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后在浏览器中打开：

```text
http://127.0.0.1:8000/
```

点击「开始突入」，浏览器会请求锁定鼠标。首次进入时请允许 Pointer Lock，并确保浏览器启用了 WebGL / 硬件加速。

停止服务器：

```text
Ctrl+C
```

也可以直接使用 VS Code Live Server、Nginx 或其他静态文件服务器。建议通过 HTTP 运行，而不是直接双击 `index.html`，这样可以避免浏览器对本地脚本和资源加载的限制。

## Agent 自动化实现流程

本项目采用“设计计划 → Implementer 实现 → Reviewer 审查 → 浏览器验证 → Git 发布”的自动化协作流程：

1. **需求与方案设计**
   - 明确平台、像素风格、第一人称操作、Boss、三武器和角色技能；
   - 约束为本地离线运行，不使用 CDN、外部模型、图片、音频或网络请求；
   - 先拆分场景、输入、战斗、Boss 状态机和视觉系统。
2. **Implementer 实现**
   - 由 Implementer 按最终计划创建和修改游戏文件；
   - 先完成可玩的 3D FPS 基础 Demo，再加入工业场景、程序化材质和关卡流程；
   - 后续独立细化三把第一人称武器及其动画。
3. **Reviewer 只读审查**
   - Reviewer 不修改实现，只检查功能是否符合计划；
   - 检查武器切换、武器数值与模型挂接、Boss 阶段、技能冷却、资源依赖和渲染器兼容性；
   - 检查是否出现外部 URL、CDN、fetch、XHR、WebSocket 或每帧创建 Mesh 等问题。
4. **本地验证**
   - 使用 `node --check` 进行 JavaScript 语法检查；
   - 使用本地 HTTP 服务和 Chromium + SwiftShader 验证 WebGL 启动；
   - 验证 Pointer Lock、波次启动、射击、弹药消耗、武器切换、技能冷却、暂停、Boss 击败、出口胜利、死亡和重试；
   - 生成入口、管线走廊和 Boss 核心区截图检查视觉结果。
5. **Git 维护与发布**
   - 将可运行游戏、离线依赖和 README 统一放入独立仓库；
   - 提交清晰的版本记录；
   - 推送到 GitHub，便于后续继续开发和回滚。
