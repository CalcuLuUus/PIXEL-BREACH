# PIXEL//BREACH — 落日船坞 V8

离线、原创的浏览器第一人称科幻射击游戏。穿过安检区、集装箱堆场和装卸维修区，在干船坞击败零号守门者，从七号泊位撤离。

## 启动

在仓库根目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

用桌面浏览器打开 `http://127.0.0.1:8000/`。点击「开始突入」解锁声音并请求指针锁定。指针锁定失败时，可以在画面内移动鼠标转向。主菜单提供声音预览和船坞镜头切换。

游戏以原生 HTML、CSS、JavaScript 和本地 WebGL 渲染器运行，无构建步骤。模型、纹理、音效和音乐在本机生成，游戏资源随静态页面提供。

## 船坞与任务

- 安检闸杆靠近时自动抬起，也可用交互键确认放行。进入箱区后触发四架漂移哨兵。东侧观察栈道可从两端登上，维修通道与中央轨道均可通行。
- 清除箱区并进入维修区后，第二波部署四架哨兵和两座炮台。维修台可移位吊具，工灯和木箱可被击破。
- 清除第二波后，进入开放船坞触发守门者。任务目标、增援标记、攻击预警、局部灯光、音乐和可选电台字幕随战况变化。
- 守门者拥有 **500 HP**，在 **330 HP** 和 **150 HP** 切换阶段。护盾挡下伤害，护盾结束后提供双倍伤害窗口，二、三阶段分别为 1.7 秒和 1.35 秒。阶段三加入追踪弹和带缺口的双环冲击波。阶段切换和死亡驱动装甲、散热片、雾和湿表面染色。守门者解体时出口立即解锁。
- 两个补给点分别位于入口和维修区。足够近时按住交互键 0.9 秒，获得最多 40 HP、50 枚步枪备弹和 16 枚散射器备弹。移步、离开、跳跃或松键会中断。两个站点独立冷却 35 秒。

| 默认键位 | 功能 |
| --- | --- |
| WASD、鼠标 | 移动、转向 |
| 左键、1 / 2 / 3 | 攻击、切换步枪、散射器或相位刃 |
| R、I | 换弹、检查武器 |
| Space、Shift | 跳跃、冲刺 |
| Q、F | 相位突进、过载脉冲 |
| E | 接入控制台、按住补给、接入出口 |
| X | 跳过当前镜头 |
| Esc、Enter | 暂停、开始或继续 |

步枪是自动武器，弹匣 30 发、备弹 120 发。散射器每次发射五发散射弹，弹匣 8 发、备弹 48 发。远程弹匣打空后有备弹时自动装填。相位刃挥砍约 0.4 秒，每次挥砍只对同一目标结算一次。每次起跳可以使用一次空中突进。

## 画质、声音和可访问性

| 档位 | 起始内部尺寸 | 自动缩放范围 | 光照与反射 | 后处理 |
| --- | --- | --- | --- | --- |
| High | 1920×1080 | 0.75–1.00 | 双覆盖 2048 太阳阴影，海面和两处积水反射 | ACES、Bloom、FXAA、深度接触遮蔽和港雾。设备支持时启用 4× MSAA |
| Balanced | 1600×900 | 0.80–1.00 | 1024 太阳阴影，海面平面反射 | ACES、Bloom、FXAA、深度接触遮蔽和港雾 |
| Fallback | 960×540 | 0.75–1.00 | 接触阴影、程序化天空与海面近似 | 前向高光压缩、雾和设备可用的 MSAA |

默认请求 High。可以在设置中选档，也可用 `?quality=high`、`?quality=balanced`、`?quality=fallback` 覆盖本次启动。WebGL1 选择 Fallback。高精度颜色附件不可用时，高/均衡档可使用 RGBA8。返回上一有效的内部尺寸或自动降档时，诊断会报告原因。上下文丢失会停止模拟并显示重载入口。

高、均衡档使用线性 GGX 光照、sRGB 颜色输入输出和本地纹理数组。表面使用法线、粗糙度、AO 和磨损遮罩。积水反射随距离、表面粗糙度和湿度变化。海面与水洼使用有限槽位的扰动，单帧最多更新一处平面反射。兼容档使用平滑前向材质、较低纹理开销和程序化水面。GPU 诊断展示功能实际启用情况。

「设置」可调整动态分辨率、手动缩放上限、阴影和纹理质量、反射、后处理、Bloom、音量、视野、灵敏度及镜头晃动。突进模糊默认关闭。低刺激模式关闭闪屏和战斗镜头偏移，高对比度模式加强 HUD 轮廓。任务状态也通过文字与符号呈现。画质档位、阴影和纹理需要点「应用画质并重新载入」重建资源，暂停时应用会重新开始任务。设置、最高进度、通关次数、最快用时与最高击杀保存在当前浏览器，可恢复默认设置。

武器、脚步、材料冲击和机械敌人使用本地合成音效。环境声按区域混合，音乐在任务节点切换节奏和声部。音量分为总音量、音乐、战斗音效、电台、环境和界面。电台使用提示音与字幕。浏览器拒绝音频时仍可继续游戏。

## 代码与资源

- `game.js` 接入碰撞、移动、攻击和船坞渲染，调度各系统及有界特效池。
- `src/core/` 提供事件总线、可复现的随机源、动态分辨率和 `PBAssets` 本地资产注册表。注册表记录程序化模型、材质和纹理集合的命名空间、状态、引用计数、复用次数与失败信息，并可通过诊断快照查看；区域资源释放时可按引用计数回收登记。
- `src/scene/` 管理观察栈道、闸机、吊具和可破坏物件。邻区标识空闲时上传，离开后释放各自纹理并同步更新资产引用计数，最多同时驻留三个区域。共享的基础船坞资源可反复使用；这部分是区域标识纹理流送，不是完整 GLB/纹理场景流送。
- `src/dock-art.js`、`src/model-kit.js`、`src/port-setpieces.js` 和 `src/combat-visuals.js` 提供本地生成的纹理、标牌、场景、机械模型和材料命中特效。船坞几何按区域与材料合批，远处货箱、栏杆、灯杆和甲板铆件使用批量布局。
- `src/audio/`、`src/camera/` 和 `src/ui/` 管理空间声音、过场和本地设置。音效池为 24 个同播槽，弹痕池为 40 或 24 个槽，水面 shader 扰动为 4 个槽。 `vendor/three.min.js` 包含项目本地渲染管线。

场景和机械以程序化、分层部件方式构建。`PBAssets` 负责登记本地生成资源，但当前仍没有外部模型/纹理/音频文件导入器；区域流送覆盖区域标识纹理，关卡和战斗基础资源在启动时准备。High/Balanced 的表面细节是程序化纹理数组中的法线、粗糙度和 AO 通道，不等同于外部扫描资产。主要渲染后端为 WebGL2，WebGL1 的低 uniform 兼容路径进一步精简材质与灯光。

## 诊断与复现

浏览器控制台提供只读诊断：

```js
window.__PB_RENDERING__.snapshot()
window.__PB_LIGHTING__.snapshot()
window.__PB_CINEMATIC_FX__.snapshot()
window.__PB_MISSION__.snapshot()
```

渲染快照包含实际上下文、GPU、画布尺寸、动态缩放帧时间、可见三角形、提交绘制次数、反射更新、后处理通道和资源计数，也会区分真实启用的 `skyReflections`、`volumetricScattering` 与相应的程序化近似字段。任务快照包含区域、角色状态、武器、Boss 阶段、出入口、补给、音频池和 `PBAssets` 资源统计。快照区分可见场景三角形与包含多通道的绘制提交统计。

- `?capture=entrance|yard|loading|boss|extraction` 固定机位并隐藏菜单。
- `?benchmark=1&seed=8027` 提供 `await window.__PB_BENCHMARK__.sample(240)`，可以在游戏中采样最近运行的帧间隔。可传 `renderScale` 钳制内部尺寸。
- `?qa=1` 提供仅在测试页面使用的固定步长和状态布置接口。浏览器回归用键鼠推进输入，并在特定位置布置敌人伤害，以可重复地覆盖流程分支。

```bash
find . -name '*.js' -not -path './.git/*' -print0 | xargs -0 -n1 node --check
node --test tests/*.test.cjs
git diff --check

# 浏览器脚本使用测试机已有的 Playwright 和浏览器。
PB_TEST_URL=http://127.0.0.1:8000/ node tests/browser-v8.cjs
PB_ANGLE_VULKAN=1 node tests/browser-v8.cjs
PB_SWIFTSHADER=1 node tests/browser-v8.cjs
PB_CAPTURE_DIR=/tmp/pb-v8-captures node tests/benchmark-v8.cjs
```

`PB_PLAYWRIGHT_MODULE` 可指定现有的测试模块路径。浏览器脚本拦截并报告跨源游戏请求、HTTP 错误和运行异常。 `tests/benchmark-v8.cjs` 在硬件 Chromium 上布置第一波和狂暴战斗，并为两段场景各采样 240 帧。可用 `PB_VIDEO_DIR` 另行录制本地验证视频。仓库中的演示视频是历史版本录屏。

## 验证结果

本次工作区已完成以下可重复验证：

- `node --check`：仓库内 JavaScript 全部通过；
- `node --test tests/*.test.cjs`：12 项单元测试全部通过，包含资产注册表、画质降级、动态分辨率、任务流和设置迁移；
- Chromium + SwiftShader：V8 完整浏览器回归通过，覆盖 High、Balanced、Fallback、WebGL1 模拟、HDR 降级、设置、音频故障、上下文丢失、波次、守门者三阶段、补给、暂停、失败重试和撤离；
- Chromium + SwiftShader Fallback：兼容路径回归通过；
- 离线资源审计和 `git diff --check` 通过。

当前环境没有真实独立 GPU，因此 SwiftShader 结果只用于启动、兼容性和玩法回归，不作为 High 性能证明。真实 GPU 的平均帧时间、峰值帧时间和持续内存趋势仍需在目标硬件上独立采样。

浏览器脚本会拦截跨源请求、HTTP 错误和运行异常。运行时资源均使用本地相对路径；程序化模型、材质、纹理和 Web Audio 资源可通过 `PBAssets` 与各诊断快照检查。
