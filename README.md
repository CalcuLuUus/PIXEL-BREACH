# PIXEL//BREACH — 落日船坞

一个运行在桌面浏览器中的像素风 3D 第一人称射击 Demo。

玩家从落日船坞的入口堆场出发，穿过集装箱区与装卸平台，在开放船坞击败三阶段 Boss「零号守门者」，最后从码头尽头的出口撤离。

项目采用原生 HTML、CSS 和 JavaScript 实现，不需要构建工具、包管理器、外部模型或联网服务。场景、武器、敌人和灯光均由程序化几何与材质生成。

## 游戏简介

**PIXEL//BREACH** 将低分辨率像素画面与户外落日港口结合起来：

- 内部渲染分辨率为 `640×360`，通过 CSS 像素化放大；
- 场景为程序化户外船坞：集装箱、装卸平台、维修龙门架、轨道吊、叉车、系缆桩、护栏、水面与落日天空；
- 采用第一人称视角、鼠标转向和 Pointer Lock；
- 关卡线性推进：入口堆场 → 集装箱区 → 装卸平台 → 开放 Boss 船坞 → 撤离码头；
- 可步行区域约为旧室内场景的两倍，同时保持原渲染分辨率和像素质感。

## 当前实现的功能

### 核心玩法

- 3D 第一人称移动、鼠标视角和 Pointer Lock；
- WASD 移动、`Shift` 冲刺和圆形碰撞限制；
- `Space` 跳跃：重力、落地检测、明确的可站立顶面白名单；
- 低集装箱、木箱、托盘和维修台阶可跳上或直接跨上，高层堆叠不可攀爬；
- 左键攻击、准星和命中反馈；
- 两波敌人后进入 Boss，Boss 击败后解锁出口；
- 靠近出口按 `E` 撤离；
- 受伤、死亡、重试、暂停和胜利流程。

### 跳跃与相位突进

- `Space` 仅在落地状态起跳，跳跃高度足以登上低箱，但不足以爬上 2 m 以上的集装箱堆；
- 可站立表面采用显式白名单，不依赖视觉模型自动推断；
- `Q` 相位突进仍提供短暂无敌，但不能穿过碰撞体；
- 空中每次跳跃只能使用一次空中突进，落地、死亡或重试后重置；
- 地面突进与空中突进共用冷却，HUD 显示冷却状态。

### 三种武器

1. **脉冲步枪**
   - 自动连射；
   - 30 发弹匣、120 发备用弹药；
   - Hitscan 远程攻击；
   - 换弹时间约 `1.25 s`。
2. **裂能散射器**
   - 单次发射五发散射弹；
   - 8 发弹匣、48 发备用弹药；
   - 近距离爆发伤害；
   - 换弹时间约 `1.1 s`。
3. **相位刃**
   - 无弹药限制；
   - 前方扇形近战攻击；
   - 约 `0.4 s` 的可见挥砍，命中窗口约 `0.10–0.23 s`；
   - 每次挥砍对同一目标最多结算一次，可击退敌人并处理附近的敌方子弹。

三把武器均有独立第一人称 ViewModel。步枪换弹包含枪身下压、弹匣脱落/回插和拉栓阶段；散射器换弹包含枪身倾斜、弹仓门开启、转鼓旋转和弹壳装填；相位刃有独立的挥砍姿态。弹药与伤害数值沿用原版本。

远程武器弹匣打空且仍有备弹时会自动换弹。HUD 显示 `RELOADING` 与装填进度百分比；相位刃不参与换弹。

### 角色技能

- `Shift`：普通冲刺；
- `Q`：相位突进，短时间快速移动并获得无敌效果，不能穿墙；
- `F`：过载脉冲，清除附近普通敌方子弹，对普通敌人造成伤害并减速，对 Boss 造成受限伤害；
- 技能具有冷却时间和 HUD 状态显示。

### 补给点

关卡中恰好有两个固定补给点：

- 入口堆场补给点；
- 装卸平台维修区补给点，位于 Boss 船坞之前，不在 Boss  arena 中心。

交互规则：

- 靠近后按住 `E` 约 `0.9 s`；
- 移动、松开 `E`、离开范围或跳起会中断；
- 补给过程中不能攻击，但受到的伤害仍然生效；
- 每个补给点独立冷却 `35 s`；
- 成功补给恢复 `+40 HP`、步枪备弹 `+50`、散射器备弹 `+16`，均按上限截断；
- 如果 HP 与两种远程备弹都已满，不会消耗冷却；
- HUD 面板显示 `READY`、`SUPPLYING`、`COOLDOWN` 或 `FULL`，场景灯具与地面环同步变色。

补给点的 `E` 交互与出口的 `E` 交互使用不同距离判定，不会互相覆盖。

### 敌人与 Boss

- 第一波：4 个漂移哨兵，从集装箱区进入；
- 第二波：4 个漂移哨兵与 2 个固定炮台，在装卸平台交火；
- Boss：零号守门者，最大 HP 为 **500**；
- Boss 阶段：
  - 第一阶段：`500–331 HP`，横向移动、直线能量弹和落点预警；
  - 第二阶段：`330–151 HP`，环形护盾、激光/屏障、核心暴露和增援；
  - 第三阶段：`≤150 HP`，进入 `ENRAGED`。

暴怒阶段只触发一次，包含红黑核心与装甲配色、HUD `ENRAGED`、红屏闪烁和一次径向弹幕爆发。暴怒后攻击间隔缩短约 25%、移动速度提高约 15–20%，并加入：

- 预警后的三向扇形弹幕；
- 2–3 枚有限存活时间的追踪弹；
- 两圈错位、带缺口的冲击波；
- 更短的核心暴露窗口。

Boss 不自我治疗，不会被单次伤害跳过阶段，也不会无限召唤；召唤受数量上限和冷却限制。Boss 死亡后出口保持原有的解锁与撤离流程。

### 视觉与技术

- 本地离线资源，不使用 CDN、外部图片、模型、音频或字体；
- `vendor/three.min.js` 是项目内置的本地 Three.js-compatible WebGL 子集，不是运行时下载的官方 CDN 文件；
- `640×360` 内部渲染，CSS 像素化放大，保持 16:9；
- 户外落日方向光、蓝紫色环境光、程序化天空渐变、太阳圆盘/光晕和距离雾；
- 集装箱、码头、沥青、混凝土、锈蚀钢、海水和暖色灯具的程序化材质批次；
- 固定 6 个候选本地点光源，每帧只启用距离/优先级最高的 5 个（`MAX_LOCAL_LIGHTS=5`）；
- 钢、锈蚀钢、混凝土、海面和 Boss 表面使用有限的 `specular` / `roughness` 参数生成像素化高光，不实现完整 PBR；
- 程序化静态 AO / 接触阴影、固定 12 槽动态接触阴影；
- 落日光斑、水面反光条、灯具光锥和 Boss 阶段色使用加法混合近似；
- **V3 电影化光效层（CINEMATIC FX）**：
  - 子弹为“白热内核 + 颜色光晕 + 短暂拖尾”，拖尾从固定池复用；
  - 玩家 Hitscan 曳光弹为白热芯、彩色中层、宽光晕和命中端闪点；
  - Boss 激光包含预警线、充能收束、白热芯束、彩色中层、外层光晕和端点冲击；
  - 灯具、核心、Boss 能量塔和出口使用固定上限的加法体积片；
  - 命中火花、冲击环、枪口多层闪光、Boss 冲击波、相位刃弧光和屏幕闪光均从固定池复用；
  - 地面/墙面使用程序化彩色反射条与“湿金属”高光，属于假反射，不是 SSR/光线追踪；
  - 所有瞬时 Mesh/Material/Geometry 在启动时预建并复用，战斗循环不创建新的 Mesh/Material/Geometry；
  - 只读检查接口：`window.__PB_CINEMATIC_FX__.snapshot()` 与 `window.__PB_LIGHTING__.snapshot()`。

固定池与上限：

| 系统 | 上限 |
| --- | --- |
| 子弹视觉 / 子弹拖尾 | 90 / 32 |
| 玩家曳光弹 | 28 |
| 命中火花 | 48 |
| 冲击环 | 10 |
| 相位刃弧光 | 6 |
| Boss 激光 | 3（≤ 8） |
| Boss 预警圈 | 12 |
| Boss 冲击波 | 4 |
| 体积光束 | 20 组（双层） |
| 动态反射条 | 16 |
| 粒子 | 190（启动预建） |
| 同时生效本地点光源 | 5（6 个候选） |
| 动态接触阴影槽 | 12 |
| 哨兵 / 炮台实体池 | 8 / 4（启动预建，隐藏复用） |
| Boss 实体池 | 1（启动预建，隐藏复用） |

### 程序化近似与限制

- 场景、天空、水面反光、接触阴影和体积光均为程序化近似，不是写实渲染；
- 不包含 Shadow Map、全屏 Bloom、PBR、SSAO、SSR、全局光照或光线追踪；
- 没有纹理贴图、法线贴图或骨骼动画，武器换弹与挥砍由分层几何体变换实现；
- 水体为平面和反光条的组合，没有真实折射、焦散或流体模拟；
- 户外远景为程序化剪影和天空渐变，不是开放世界；
- 自动化静态检查不能替代真实浏览器中的 WebGL、Pointer Lock 和输入手感验证。

## 安装与运行

### 环境要求

- 支持 WebGL 的现代桌面浏览器；
- Python 3，或者任意静态 HTTP 文件服务器；
- 不需要 `npm install`，也不需要下载额外依赖。

### 使用 Python 启动

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后在浏览器中打开：

```text
http://127.0.0.1:8000/
```

点击「开始突入」后，浏览器会请求锁定鼠标。首次进入时请允许 Pointer Lock，并确保浏览器启用了 WebGL / 硬件加速。

停止服务器：

```text
Ctrl+C
```

也可以使用任意静态文件服务器。建议通过 HTTP 运行，而不是直接双击 `index.html`。
